🛡️ Demo: Ataque Bloqueado

❌ Sin BFF (Vulnerable)

$ curl saldo-service/cuentas \ -H "Auth: Bearer USER_TOKEN" ✅ 200 OK { "cuentas": [ { "saldo": 45000 } ] } ❌ ACCESO PERMITIDO VULNERABLE!

✅ Con BFF (Protegido)

$ curl saldo-service/cuentas \ -H "Auth: Bearer USER_TOKEN" ❌ 401 Unauthorized { "error": "Service token required" } ✅ ATAQUE BLOQUEADO PROTEGIDO!
